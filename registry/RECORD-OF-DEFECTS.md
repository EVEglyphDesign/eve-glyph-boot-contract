# Record of Defect — superseded

This register was renamed on 2026-09-12 to the **Record of Suffering (ROS)**.

- Current register: [`registry/RECORD-OF-SUFFERING.md`](./RECORD-OF-SUFFERING.md)

All entries were carried across unchanged, including their original `ROD-`, `C-`, `R-`,
`L-`, `D-`, `SIN-`, and `EgD-SIN-` identifiers. Nothing was deleted. The rename adds a
**fault** column ranked from the operator's perspective — Agent, Instruction,
Tooling / Platform, Upstream — while retaining the existing class taxonomy. New entries
are logged in the ROS as `ROS-YYYY-MM-DD-NN`.

The framing change is deliberate: "defect" reads like a bug in a build, "sin" reads like
the model apologising to itself, and neither carries what actually happened, which is
that the operator absorbed the cost. The register is kept from the operator's chair.

This file is kept so existing links do not break.
