# SIN Defect Register — superseded

This register was renamed on 2026-09-09 to the **Record of Defect (ROD)**.

- Current register: [`registry/RECORD-OF-DEFECTS.md`](./RECORD-OF-DEFECTS.md)

All entries were carried across unchanged, including their original `SIN-` identifiers.
Nothing was deleted. New entries are logged in the ROD as `ROD-YYYY-MM-DD-NN`, and the
class list now separates a genuine contract breach from a **technical expectations gap**
(class `G`), which is reviewed rather than corrected.

This file is kept so existing links do not break.
